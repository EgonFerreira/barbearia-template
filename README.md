# Template de Barbearia

Landing page responsiva para barbearias, feita com HTML e CSS.

**Demonstração:** https://barbearia-template-pt.netlify.app

## O que tem
- Secção principal com imagem de fundo e botão de marcação
- Serviços e preços em cartões
- Galeria de fotos com efeito de zoom
- Contacto com botão de WhatsApp
- Menu responsivo: adapta-se ao telemóvel

## Tecnologias e conceitos usados
- HTML semântico
- CSS: Grid, Flexbox, variáveis (custom properties), media queries, transições
- Imagem de fundo com gradiente por cima, para o texto ficar legível
- Animação do poste de barbeiro só com CSS
- Publicado no Netlify

## Como personalizar
- Textos e links: editar o ficheiro index.html
- Cores: alterar as variáveis no início do style.css
- Fotos: substituir os ficheiros na pasta fotos, mantendo os nomes
